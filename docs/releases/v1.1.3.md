# SFDownloader 1.1.3

## Personalização

- Temas personalizados com variações de wallpaper e perfis de cores, fontes e formatos.
- Cyberpunk com Songbird e duas variações de V; GTA San Andreas com dez wallpapers; OnePunchMan com Saitama, Genos, Tatsumaki e Fubuki; Naruto reúne Bárion e Hinata.
- Importação de temas locais por ZIP na Personalização, com configuração, miniaturas e imagens para diferentes tamanhos de janela. Os pacotes não executam scripts nem carregam recursos externos.
- Catálogo oficial separado dos temas locais, com seleção e remoção próprias.
- Cache do catálogo preparado na abertura e miniaturas otimizadas para reduzir o custo de abrir a lista.
- Ícones animados ao passar o mouse, respeitando movimento reduzido do sistema.

## Mídia e atualização

- Consulta de vídeo/música com janela compacta e expansão suave ao carregar os detalhes.
- Melhor legibilidade em janelas auxiliares dos temas personalizados.
- Botão, notas da versão e modais de atualização com visual revisado.
- Download da atualização informa tamanho total, velocidade e tempo restante quando esses dados estão disponíveis.
- Janela externa de instalação usa o ícone do SFDownloader na barra de tarefas.
- Limpeza do setup usado e dos instaladores antigos após uma instalação bem-sucedida. Falhas de instalação preservam o setup para nova tentativa.

## Instalação

Windows 10/11 de 64 bits. Use o arquivo `SFDownloader_1.1.3_x64-setup.exe` para instalar ou atualizar. O MSI e o pacote portátil completo também estão disponíveis. A extensão permanece na versão 0.3.8, com XPI Firefox assinado.

A build foi feita localmente; nenhum build foi executado no GitHub Actions.

## Validação e limites

O aplicativo permanece em beta. Os testes frontend e a build local foram verificados; temas locais e a atualização entre versões precisam de validação manual no aplicativo instalado. O executável de testes Rust encontra `STATUS_ENTRYPOINT_NOT_FOUND` neste ambiente; a checagem estática Rust é executada separadamente.

O motor torrent/P2P mantém os limites da versão beta, incluindo ausência de seeding contínuo após concluir. Nenhuma nova validação de interoperabilidade torrent é afirmada nesta release.

Ferramentas de mídia: yt-dlp, Deno e FFmpeg/ffprobe LGPL 3. Licenças, avisos e fontes correspondentes acompanham os pacotes da release. O arquivo `media-sources.zip` contém fontes das ferramentas; não é necessário para instalar o aplicativo.
