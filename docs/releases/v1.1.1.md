# SFDownloader 1.1.1

## Correção dos temas na versão instalada

- Corrigido o erro **CSS inválido / Invalid CSS** ao aplicar temas de jogos e temas CSS no aplicativo instalado.
- Os estilos dinâmicos passam a usar o nonce autorizado pelo Tauri, respeitando a política de segurança de conteúdo (CSP), sem desativá-la.
- Adicionado teste de regressão para o nonce usado na validação e aplicação do CSS.

Os temas já baixados permanecem no cache. Após atualizar, aplique novamente o tema desejado.

## Instalação e distribuição

Windows 10/11, 64 bits. Baixe o **x64-setup.exe** ou atualize pelo aplicativo. Também disponíveis MSI e ZIP portátil completo com ferramentas de mídia.

A extensão permanece na versão **0.3.8**. Esta atualização não altera os motores HTTP, mídia ou BitTorrent/P2P.

Build compilada localmente, sem GitHub Actions. FFmpeg/ffprobe LGPL 3, yt-dlp e Deno acompanham os pacotes completos; licenças e fontes correspondentes estão na release.
